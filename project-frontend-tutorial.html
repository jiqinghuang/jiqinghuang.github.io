项目简介Overview

>_

为谁而做Who It Is For

面向已经会 Python、C、MATLAB 或 R 的学习者，不重复讲变量和循环，而是专注于 HTML 结构、CSS 布局和浏览器特有的工作方式。Designed for learners who already know Python, C, MATLAB or R. Instead of repeating variables and loops, it focuses on HTML structure, CSS layout and browser-specific ways of working.

DOM

为什么做它Why I Built It

HTML 和 CSS 是进入 DOM、JavaScript、TypeScript 以及 AI 网页应用的基础。教程把这些概念连接到树、表格、向量化和数据可视化等已有直觉。HTML and CSS are the foundation for the DOM, JavaScript, TypeScript and AI web applications. The tutorial connects them to familiar ideas such as trees, tables, vectorized operations and data visualization.

CN

语言边界Language Scope

个人网站的项目介绍支持中英文切换；教程正文暂时保持中文，以保留完整的教学语境和原有表达。The project overview is bilingual, while the tutorial content remains in Chinese to preserve its original teaching context and learning flow.

离线优先Offline First

纯 HTML、CSS 和原生 JavaScript，不依赖框架、构建工具、CDN 或外部字体，直接打开即可学习。Pure HTML, CSS and vanilla JavaScript with no framework, build tool, CDN or external font dependency. It can be opened directly.

即时练习Immediate Practice

练习场使用 sandbox iframe 实时渲染 HTML/CSS，并用浏览器本地存储保留练习代码。The playground renders HTML/CSS in a sandboxed iframe and keeps practice code in browser local storage.

公共组件Shared Components

公共导航、章节翻页、代码复制、跳到正文和进度数据由共享脚本统一维护。Shared scripts provide navigation, chapter paging, code copying, skip links and progress data.

质量意识Quality Mindset

内容同时检查响应式、深色模式、打印、键盘焦点、表单语义、图片替代文本和动效偏好。The project checks responsive layouts, dark mode, printing, keyboard focus, form semantics, image alternatives and motion preferences.

我的工作My Role

负责教程的课程结构设计、HTML/CSS 内容编写、示例和练习设计、交互功能实现，以及无障碍、响应式和静态质量检查。 Designed the curriculum structure, wrote the HTML/CSS content, created examples and exercises, implemented the interactive features, and performed accessibility, responsive and static QA checks.
