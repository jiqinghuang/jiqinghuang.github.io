为什么做它Why I Built It

扫雷的乐趣藏在细节里：双键和弦、按压预览、首点保雷。把这些手感复刻出来，再顺手把架构做成可测试、可回归的小型范本，一举两得。The joy of minesweeper lives in the details: two-button chords, press previews, first-click safety. Reproducing that feel — while building a testable, regression-proof architecture along the way — kills two birds with one stone.

✓

严格经典规则Strictly Classic Rules

首点保雷（严格经典：首点仍可能直接翻出数字）、旗挡 flood 展开而问号不挡、和弦翻错旗会踩雷判负、剩余雷数可为负——行为逐条对照原版考证。First-click safety (strict classic — the first click may still open a number), flags block flood while question marks don't, a wrong flag in a chord detonates, and the mine counter can go negative. Every behavior verified against the original.

经典三级Three Classic Levels

初级 9×9×10、中级 16×16×40、高级 16×30×99；七段 LED 计数器支持负数（经典的 -01 式显示），计时首翻启动、胜负冻结、上限 999 秒。Beginner 9×9×10, Intermediate 16×16×40, Expert 16×30×99. The seven-segment LED counter goes negative (classic -01 style); the clock starts on the first reveal, freezes on win/loss and caps at 999 seconds.

手势手感Gesture Feel

按住拖动时按压跟随、拖出取消；双键/中键和弦预压邻居且两种按键顺序都能触发；窗口失焦自动复位手势。键盘 Alt+G 菜单 / F2 重开，触屏点按翻开、长按插旗。Press-and-drag previews follow the pointer and cancel on exit; two-button and middle-button chords work in either press order with neighbor previews; losing window focus resets all gestures. Keyboard: Alt+G menu, F2 restart. Touch: tap to reveal, long-press to flag.

终局图块Endgame Tiles

对照原版 winmine 的 DrawMine 图块表逐格复刻：踩中的雷红底、未标出的雷亮出、错旗显示被红叉划掉的雷、问号保持原样；胜利时旗稳稳落在雷上。Reproduced tile by tile from the original winmine DrawMine table: the detonated mine on red, unflagged mines revealed, wrong flags struck through with a red cross, question marks left untouched — and on victory every flag sits on a mine.

工程实现Implementation

TypeScript 源码 → tsc 编译 → 纯静态产物，零图片零字体TypeScript source → tsc build → purely static output — no images, no fonts

引擎与 UI 分离Engine / UI Separation

engine 不知道 DOM 的存在，以 UMD 双端加载；浏览器加载的 dist 产物与 Node 测试 require 的是同一份代码，规则可被完全自动化验证。The engine knows nothing about the DOM and loads via UMD. The dist artifact the browser loads is the very same file the Node tests require, so every rule is fully automatable.

可测试性设计Testability by Design

随机源与计时器全部可注入：种子 PRNG 复现任意局面，测试直接指定雷位；计时对时钟回拨免疫，胜负时刻精确冻结。Random source and clock are both injectable: a seeded PRNG reproduces any board, tests can plant exact mine layouts, and the timer is immune to clock rollbacks and freezes exactly at game over.

独立对拍Independent Cross-checking

测试不信任被测代码：flood 展开与邻雷计数各有一份独立实现做对拍，300 种子 × 3 级别验证首点保雷，50 种子整局自洽对拍胜负判定。The tests do not trust the code under test: flood expansion and adjacency counts are cross-checked against independent implementations, 300 seeds × 3 levels verify first-click safety, and 50 full random games check win/loss consistency.

回归测试即文档Regression Tests as Documentation

每条回归用例的注释都记录着历史 bug 的根因——越界下标凑出的假胜利、错旗图形拼出外壳的红叉、和弦手势泄漏的误翻……测试就是这份复刻的设计文档。Every regression test documents the root cause of a real historical bug — fake wins from out-of-range indices, the red cross rendered outside its SVG shell, a leaked mis-click from the chord gesture. The test suite is the design document.

UI 接线测试UI Wiring Tests

用最小 DOM stub 真正执行 dist/ui.js（线上同一份），覆盖手势状态机的按键顺序、拖动跟随、失焦复位、终局渲染与计时器生命周期；渲染断言拆到 SVG 结构级，抓「有字符串但不显示」的 bug。A minimal DOM stub executes the real dist/ui.js — the same file served online — covering gesture press orders, drag following, focus-loss resets, endgame rendering and timer lifecycle. Rendering asserts go down to SVG structure to catch "the string is there but nothing shows" bugs.

CI 护栏CI Guards

GitHub Actions 每次推送执行类型检查、构建与双套测试，并校验 dist/ 与 src/ 同步；关键用例经变异测试验证——临时还原旧 bug 必须让测试变红，确保用例都是「活的」。GitHub Actions runs typecheck, build and both suites on every push, and verifies dist/ matches src/. Key tests are mutation-verified: temporarily reintroducing an old bug must turn the suite red.

我的工作My Role

独立完成规则考证（逐项对照原版 winmine 行为）、引擎与界面开发、双套测试体系建设与 CI 闭环；并组织双模型 AI 代码审阅交叉验证、用变异测试验证修复的有效性。 Independently researched the original winmine behavior, built the engine and UI, established both test suites and the CI loop, and organized a dual-model AI code review with cross-validation — verifying every fix with mutation testing.
