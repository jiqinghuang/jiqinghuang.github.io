项目简介Overview

不甩答案，而是把解题思路一步步讲给你听Not just answers — the reasoning, one understandable step at a time

>_

为谁而做Who It Is For

给想学会数独解题思路的人。大多数求解器只给终盘，这个项目把每一格的来龙去脉用初学者能懂中文讲清楚。For anyone who wants to learn how to solve sudoku, not just get the solution. Every cell's reasoning is explained in plain, beginner-friendly Chinese.

?

为什么做它Why I Built It

市面上的求解器大多只输出结果。把推理过程拆成可回放、可核对的步骤，既是教学工具，也是对约束传播算法的一次完整实践。Most solvers only output the final grid. Turning the reasoning into replayable, verifiable steps makes it both a teaching tool and a hands-on study of constraint propagation.

✓

诚实标注Honest Labeling

逻辑推不动时会明确标出「试填」并自动回溯验证唯一解——绝不把猜测冒充成推理，这是教学工具的底线。When logic runs out, guess steps are clearly flagged in amber and uniqueness is verified by backtracking. Guesses are never dressed up as logic.

推理技巧Techniques

唯一候选数、行/列/宫唯一、区块摒除、显性数对/三数组、隐性数对/三数组、X-Wing；默认同类确定格批量填入（单步最多 4 格、最显眼的先讲），也可切换「一步一格」逐步讲解，「展开逐格理由」让多格步骤依然清晰。Naked singles, hidden singles, locked candidates, naked & hidden subsets and X-Wing, with same-technique batch steps by default (max 4 cells per step, most visible first), an optional one-cell-per-step teaching mode, and collapsible per-cell reasoning that keeps multi-cell steps readable.

可回放Replayable

每一步高亮涉及单元、推理格与被划掉的候选（含已消失候选的回显），支持前进、后退、自动播放和点击跳转。Every step highlights the units, focus cells and eliminated candidates, with forward/backward stepping, autoplay and click-to-jump.

可出题Puzzle Generator

从随机终盘逐格挖空，每挖一格都验证仍是唯一解；简单到专家四档难度按解题实际用到的最高技巧定级，保证可解且解唯一。Digs cells from a random solution, verifying uniqueness after every dig. Four difficulty levels graded by the hardest technique actually needed, always uniquely solvable.

工程实现Implementation

TypeScript 源码 → tsc 编译 → 纯静态产物TypeScript source → tsc build → purely static output

位运算引擎Bitwise Engine

候选数用 9 位掩码表示，约束传播 + MRV 试填回溯，空盘求解也在毫秒级完成。Candidates as 9-bit masks with constraint propagation and MRV backtracking — even an empty board solves in milliseconds.

三端复用One Bundle, Three Consumers

求解器以 UMD 形式导出：浏览器主线程与 Web Worker 加载同一份产物，Node 测试直接 require，一份代码三种用法。The solver exports via UMD: the browser main thread and the Web Worker load the very same artifact, and Node tests require it directly — one codebase, three consumers.

类型安全Type Safety

全量 TypeScript strict 模式；编译产物随仓库提交，线上加载的就是测试所验证的那份代码。Fully strict-mode TypeScript; the compiled bundle is committed, so the code online is exactly the code the tests verified.

后台线程Background Thread

求解与出题交给 Web Worker 执行，主线程始终可交互；Worker 构造失败、脚本 404 或运行出错时自动退回主线程，两条路径行为一致且都有测试覆盖。Solving and generation run in a Web Worker so the main thread stays responsive. If the worker cannot be created, 404s or throws, it falls back to the main thread — both paths behave identically and both are covered by tests.

质量保障Quality Assurance

185 条测试覆盖求解器、界面接线与 Worker 消息协议（含 Worker 异常与取消分支、两种粒度的一致性），并与独立的朴素 DFS 对拍 220 道随机题，解数完全一致。185 tests cover the solver, UI wiring and the worker message contract — including worker failure/cancel paths and consistency between the two step-granularity modes — cross-checked against an independent brute-force DFS on 220 random puzzles with identical solution counts.

CI 护栏CI Guards

GitHub Actions 每次推送自动执行类型检查与全量测试，并校验 dist/ 与 src/ 同步——改了源码忘编译、或漏提交新产物都过不了。GitHub Actions runs typecheck and the full suite on every push, and verifies that dist/ matches src/ — a forgotten build or a missing artifact cannot ship.

我的工作My Role

独立完成算法设计（位运算候选管理、约束传播、唯一解搜索）、中文推理文案撰写、界面与回放交互开发、TypeScript 迁移与全量测试建设。 Independently designed the algorithm (bitwise candidate management, constraint propagation, uniqueness search), wrote the Chinese reasoning copy, built the UI and replay interactions, and led the TypeScript migration and full test suite.
